# La Forja Colaborativa - Videojuegos

Proyecto colaborativo para el Trabajo Práctico 8 de Funcionamiento de los Sistemas Digitales.

## Estructura
```
proyecto/
├── index.html
├── css/
│   └── style.css
└── img/
    └── (imágenes de las tarjetas)
```

## Cómo colaborar (Pull Requests)

1. Hacer **fork** de este repositorio.
2. Clonar tu fork localmente.
3. Agregar tu nombre en la lista de `<ul id="lista-participantes">` de `index.html`.
4. Agregar una nueva tarjeta `<article class="tarjeta">` dentro de `#grid-tarjetas`, siguiendo la estructura de las tarjetas existentes.
5. Agregar tu imagen dentro de `img/` (ver criterios en `img/README.txt`).
6. Hacer commit y push a tu fork.
7. Abrir un Pull Request hacia este repositorio, describiendo:
   - Qué modificaciones realizaste.
   - Qué tarjeta agregaste.
   - Qué archivos modificaste.
   - Si hiciste algún ajuste para respetar la estructura original.

## Criterios visuales
- No modificar tarjetas de otros compañeros.
- Título de tarjeta: máximo 40 caracteres.
- Descripción: 1 a 2 oraciones.
- Mantener la clase `tarjeta` y su estructura interna (imagen, título, descripción).
